# 02 - Red Flag Master List

| # | Red flag | What to look for |
|---|----------|------------------|
| 1 | Sender-domain mismatch | Display name conflicts with the real address |
| 2 | Fake forwarded chains | "FW:" threads with pasted headers or odd timestamps |
| 3 | Browser-in-the-Browser (BitB) | Fake SSO pop-up that cannot be dragged outside the browser window |
| 4 | Dangerous attachments | .iso, .js, .scr, HTML smuggling links |
| 5 | Urgent bypass requests | Secrecy and skipping normal procedure |
| 6 | Requests for sensitive info | MFA codes, passwords, payment detail changes |
| 7 | Activity alerts | Sign-in warnings that link to a login page |
| 8 | MFA fatigue | Repeated unprompted push approvals |
| 9 | Callback scams (TOAD) | Phone number only, no links |
| 10 | QR code prompts | Unsolicited "scan to secure your account" |
| 11 | Deepfake meeting fraud | Voice or video impersonation demanding payment changes |

## Psychological triggers
| Trigger | How it is used |
|---------|----------------|
| Authority | Impersonating the C-suite, IT or law enforcement |
| Urgency | Artificial deadlines to trigger a fight-or-flight response |
| Curiosity | Exploiting the need to fill knowledge gaps |
| Fear / Greed | Threats of consequences or promises of unearned rewards |

## Phishing types by targeting
| Type | Description |
|------|-------------|
| Mass phishing | Generic lures mimicking big brands, high volume, low personalization |
| Spear phishing | Personalized using OSINT such as LinkedIn |
| Whaling | Targets executives for high-value wire transfers (BEC) |

## Channels beyond email
Smishing (SMS), Vishing (voice), Quishing (QR codes), Search engine phishing (SEO poisoning).
